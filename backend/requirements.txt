### Difficultés rencontrées et solutions
- Bug d'encodage UTF-8 avec psycopg2 → résolu en passant au driver pg8000
- Conflit de branches Git (main vs master) → résolu avec git branch -M main
- Historiques Git non liés (local vs distant) → résolu avec --allow-unrelated-histories
